# Claude Code Preferences

This file documents preferences and guidelines for Claude Code when working on this project.

## Commit Messages

**Do not include the Claude signature in commit messages.**

When creating commits, do NOT add:
- The "🤖 Generated with [Claude Code](https://claude.com/claude-code)" line
- The "Co-Authored-By: Claude <noreply@anthropic.com>" line

Keep commit messages clean and focused on the actual changes.
